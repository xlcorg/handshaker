The call stays in one window

A streaming method is awkward to follow in a terminal. Messages keep arriving, the status shows up at the end, and the request you just ran is easy to lose.

Handshaker keeps the address, the method, the body, and the response in one desktop window. When you want the request again, it lives in a collection.

What you can do with a service

Find methods from the address

Type a host and port. Handshaker runs server reflection and lists each service and method. Refresh reflection when the contract changes. You do not import a proto file to start.

Stay with the stream

Server streaming uses Send, which becomes Cancel while the call is open. Client streaming and bidirectional calls use Open, then Send message and End stream. Messages land in a timeline, newest first.

Leave secrets in the environment

Bearer and API key store an OS environment variable name. OAuth2 client credentials use templates, including the client secret. Collection variables and the active environment fill {{name}} when you send.

Read the answer in parts

A unary response has the body, headers, trailers, and the contract. A stream uses the same headers, trailers, and contract next to the message timeline. HTTP requests sit in the same collections.

Save the messages or assemble a file

Save messages writes one JSON array of what the server sent. When a response field is bytes, Assemble writes one file. The repository echo example streams a PNG this way on Download.

Questions

What can Handshaker call?

Unary gRPC, server streaming, client streaming, bidirectional streaming, and HTTP. HTTP methods are GET, POST, PUT, PATCH, DELETE, HEAD, and OPTIONS. Streaming methods show a stream, client, or bidi badge. Unary methods show no badge.

Where does the method list come from?

Server reflection. You type a host and port, and Handshaker lists the services on that address. There is no proto file import. If reflection is off or the server cannot be reached, the contract stays unavailable until you refresh reflection.

Which systems can I install it on?

macOS and Windows. Version 0.3.7 publishes an Apple Silicon disk image and a Windows 64 bit installer. That release has no Intel Mac build and no Linux build. The project README says Linux is untested.

How is authentication stored?

The choices are None, Bearer, API key, and OAuth2. Bearer and API key store the name of an OS environment variable. The secret stays in the environment. OAuth2 uses client credentials, and its fields are templates, including the client secret. A request can override the collection.

What can a variable template resolve to?

A collection variable, a value from the active environment, or a built in value generated when you send. Built in names are {{$guid}}, {{$guid7}}, {{$timestamp}}, {{$unixMs}}, {{$isoTimestamp}}, and {{$randomInt}}.

What does a stream look like?

Messages appear in a timeline, newest first. Headers are available from the start, and trailers arrive when the stream ends. Cancel keeps what already arrived. Save messages writes one JSON array. Assemble writes one file from a bytes field. An open stream has no request deadline. A unary call uses the deadline under Settings, then Network.

How does TLS work?

The address bar lock sets TLS on, off, or inherited from the collection. The collection default lives on its overview. You can skip certificate verification for a self signed or mismatched certificate. The app warns that skipped validation is for local or trusted endpoints.

Can I move collections to another machine?

Export writes a JSON file of one collection, or of everything. Import merges that file. Matching items update. Items that exist only on this machine stay. Nothing is deleted. Environments travel in the same file.

How do updates work?

The title bar has Check for updates. Releases are published on GitHub. The app reads the latest release manifest from that repository.

Does Handshaker cost money?

No price or plan is published. The software is MIT licensed, and that license grants use free of charge. This page does not sell a subscription.

Do I need an account?

No Handshaker account. Install the app and point it at your own servers. The download is the public GitHub release.
